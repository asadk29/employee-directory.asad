# employee-directory.asad
## Overview
 - A CRUD-based web application that allows managing employee records — built with Spring Boot, Spring MVC, Hibernate (JPA), Thymeleaf, and MySQL.
 - The app enables users to add, update, view, and delete employee details through an intuitive web interface.

## Features
 - Create, read, update, and delete (CRUD) employee records.
 - Built using Spring Boot with Thymeleaf templating engine.
 - Uses Hibernate/JPA for database persistence.
 - MVC architecture for clean separation of concerns.
 - Integrated with MySQL database.

## Tech Stack
 - Java, Spring Boot, Spring MVC, Spring Data JPA, Thymeleaf, HTML, MySQL, Maven, Eclipse.
## Setup
 - Command to clone:
   ```
   git clone https://github.com/asadk29/employee-directory.asad.git
   cd employee-directory.asad
   ```
 - Configure MySQL in application.properties:
   ```
   spring.datasource.url=jdbc:mysql://localhost:3306/employee_directory
   spring.datasource.username=YOUR_USERNAME
   spring.datasource.password=YOUR_PASSWORD
   ```
 - Run the app:
   ```
   mvn spring-boot:run
   ```
